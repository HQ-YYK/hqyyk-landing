# hqyyk-landing

Personal start page for HQYYK, a large-model-application learner.

Deployed with Cloudflare Pages as https://www.hqyyk.loc.cc/.

## Contents

- `index.html` — static landing page (no build step, no framework).
- `learning.json` — daily feed of recommended learning and deals, regenerated
  daily; consumed by the morning briefing. Contains only public learning
  recommendations, no private data.

## Preview

Open `index.html` directly in a browser, or serve the directory with any
static file server. No secrets, keys, or credentials are stored in this
repository.
